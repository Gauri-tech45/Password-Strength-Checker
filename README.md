# Password Strength Checker

## Overview

Password Strength Checker is a Python-based cybersecurity project designed to evaluate the strength of user passwords based on commonly accepted security standards. The program analyzes passwords using multiple validation criteria and provides feedback to help users create stronger and more secure passwords.

## Features
- Password length validation
- Uppercase letter detection
- Numeric digit detection
- Special character detection
- Password strength classification (Weak, Medium, Strong)
- Security recommendations for improvement
- Continuous password testing mode
- User-friendly command-line interface

## Technologies Used
- Python 3

## How It Works

### The application evaluates a password against the following criteria:
- Minimum length of 8 characters
- Presence of uppercase letters
- Presence of numeric digits
- Presence of special characters

### Based on the number of criteria satisfied, the password is categorized as:
- Weak
- Medium
- Strong

## How to Run
1. Open the project folder in a terminal.
2. Run the following command:
python password_checker.py
